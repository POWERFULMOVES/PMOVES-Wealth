# PMOVES.AI Integration Dossier

_Last updated: 2026-03-11_

## Module
- Name: PMOVES-Wealth (Firefly III)
- Path: PMOVES-Wealth/

## Purpose in PMOVES.AI
- Personal finance management service providing transaction tracking, budgeting,
  bill management, and financial reporting. Acts as the primary wealth/finance data
  source for the PMOVES ecosystem, synced to Supabase and NATS event streams via n8n.

## PMOVES Overlay Surface
- pmoves-integrations/ overlay path: `pmoves/integrations/firefly-iii/`
- Compose/profile wiring: `pmoves/compose/docker-compose.firefly.yml` (profile: `firefly`)
- Env/secret inputs:
  - `FIREFLY_APP_KEY` — Laravel encryption key (auto-generated by `brand_defaults.py`)
  - `FIREFLY_ACCESS_TOKEN` — API access token (created from Firefly UI)
  - `FIREFLY_CMD_LN_TOKEN`, `FIREFLY_PA_TOKEN_NAME` — CLI access
  - Database credentials in compose env (MariaDB)
- Auth/JWT requirements: OAuth2 personal access tokens for API; session auth for web UI

## Contracts and Topics
- NATS subjects:
  - `finance.transactions.ingested.v1` — Transaction data ingested
  - `finance.transactions.synced.v1` — Transactions synced from Firefly to Supabase
  - `finance.monthly.summary.v1` — Monthly finance CGP summary generated
- Supabase schema/tables touched: `pmoves_core.finance_transactions`, `pmoves_core.finance_accounts`
- MCP endpoints/skills: None (data access via REST API + n8n workflows)

## Boot Order and Health
- Bring-up dependency order: MariaDB (firefly-db) -> Firefly III app -> n8n (for sync)
- Health endpoints: `http://localhost:8075/api/v1/about` (API about endpoint)
- Smoke targets: `make smoke-firefly` (login page + API about endpoint)

## Hardening Notes
- Image pinning: `fireflyiii/core:latest` (upstream official image)
- Secrets source: `brand_defaults.py` auto-generates `FIREFLY_APP_KEY`;
  access tokens must be created from the Firefly III UI (Profile -> OAuth -> Personal Access Tokens)
- Network/security policy: Internal Docker network; default port `FIREFLY_PORT=8075`
  (avoids conflict with Agent Zero API on 8080)

## Mobile Applications
- **Waterfly III** (Android/iOS): Unofficial but well-maintained Firefly III mobile
  client. Connects via REST API at `http://<host>:8075/api/v1/`.
  Requires a Personal Access Token created from the Firefly III web UI.
- **Configuration**: Set the Firefly III URL in Waterfly III to your PMOVES instance
  (e.g., `https://8075.localhost` via Pinokio HTTPS proxy or Tailscale URL).
  Generate a Personal Access Token under Profile -> OAuth -> Personal Access Tokens.

## Integration Steps

### 1. Environment Variables
Edit `pmoves/env.shared` with your service-specific values. `FIREFLY_APP_KEY`
is auto-generated by `make env-setup` (via `brand_defaults.py`).

### 2. Docker Compose
The service is defined in `pmoves/compose/docker-compose.firefly.yml` and activated
via the `firefly` compose profile:
```bash
make -C pmoves up-firefly
```

### 3. Health Check
```bash
curl http://localhost:8075/api/v1/about
```

### 4. API Access
```bash
# List transactions
curl -H "Authorization: Bearer $FIREFLY_ACCESS_TOKEN" \
     http://localhost:8075/api/v1/transactions
```
